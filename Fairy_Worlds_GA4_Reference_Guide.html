💐Custom Parameters by Event Type

🧚character_select Event

Fires when a visitor picks a different character in the picker (does not fire on initial restore-from-localStorage, only on actual change).

character_id Character identifier (e.g., procedural-fairy, alien, kitty, kuromi, molly)

🌍world_enter Event

Fires every time a splat scene loads — both the first entry from the home stage and every scene-swap inside world mode.

scene_id Unique scene id (e.g., heart-pool-1-1, berry-dream-kitchen-1-0)
world World group name (e.g., Heart Pool Pavilion, Berry Dream Kitchen) — same value across versions of the same world
version Version token derived from the scene title (e.g., 1.0, 1.1, 1.1-1004). Empty string if the title has no trailing version.
from home = first entry into world mode; world = swapped scenes from the world picker while already in world mode

🥽vr_session_start Event

Fires when an immersive WebXR session is successfully started (the user clicked "✦ open in VR ✦" and the headset accepted).

No custom parameters.

⏱vr_session_end Event

Fires when the VR session ends (user exits, headset disconnects, or browser closes the session). Carries aggregate session metrics so you can answer "did anyone meaningfully use VR?" without firehose pose tracking.

duration_seconds Length of the VR session in seconds (rounded). Register as a Custom Metric so you can average it.
worlds_visited Number of scenes loaded during the VR session (i.e. scene swaps after entering VR). 0 means they entered VR and stayed in the scene they started in. Register as a Custom Metric.
max_distance_from_spawn Furthest the dolly traveled (in meters) from its spawn point during the session, reset on each scene load — so this is "max distance reached in any single scene". Tells you whether the visitor walked / locomoted around or just stood still. Register as a Custom Metric.
controller_used true if any VIVE wand trigger (selectstart) or grip (squeezestart) was pressed during the session, otherwise false. Useful for distinguishing "look-only" sessions from interactive ones.

🌸All Unique Parameters (Alphabetical)

Every parameter you can register as a custom dimension or metric:

duration_seconds VR session length in seconds (numeric — register as metric)

⭐Recommended Custom Dimensions to Register

Prioritized list (you can register up to 50 custom dimensions in GA4):

💖High Priority (Register These First)

world World group popularity — the headline insight HIGH
version Which scene version within a world gets opened HIGH
character_id Which characters resonate with visitors HIGH

🌟Medium Priority (Good Insights)

duration_seconds VR session length — register as a Custom Metric (numeric), not a dimension MEDIUM
worlds_visited VR scene-swap count — register as a Custom Metric MEDIUM
max_distance_from_spawn "Did they actually move around?" — register as a Custom Metric MEDIUM
controller_used Whether VIVE wand trigger/grip was ever pressed — distinguishes look-only from interactive sessions MEDIUM
from First-entry vs. scene-swap — useful for understanding browse vs. arrive behavior MEDIUM

🌱Low Priority (Nice to Have)

scene_id Granular per-scene id — most insights come from world + version together LOW
Pro Tip: Start with the 3 High Priority dimensions. Those alone answer "which worlds, which versions, which characters" — the questions you actually want answered. Add duration_seconds as a custom metric only if VR usage shows up at all.

🎀How to Register Custom Dimensions

  1. Go to Admin (gear icon in bottom left of Google Analytics)
  2. In the Property column, click Custom definitions
  3. Click Create custom dimension
  4. For each parameter:
    • Dimension name: Use a friendly name (e.g., "World")
    • Scope: Select "Event"
    • Description: Add a brief description
    • Event parameter: Enter the exact parameter name (e.g., world)
  5. Click Save
  6. Repeat for each parameter you want to track
For numeric values like duration_seconds: register these as Custom Metrics (not Dimensions) so you can compute average / sum / range in Explore reports.
Important: Custom dimensions can take 24-48 hours to start collecting data. Events sent BEFORE you create the dimension won't be retroactively updated, but all new events will include the dimension automatically.
Headset context: This site is being demoed at the CSU CHHS Ideation Lab on HTC VIVE Pro headsets with the standard wand-controller kit. In-VR controls:
  • Right wand trigger → next scene (cycles in array order, wraps at the end)
  • Left wand trigger → previous scene
  • Either wand grip → exit VR (returns to desktop where DOM picker is visible)
  • Left trackpad axes → walk; right trackpad axes → snap-turn (handled by vrLocomotion)
Scene order keeps world groups together (e.g. all Heart Pool Pavilion versions before any Berry Dream Kitchen scene), so trigger-cycling moves through versions of the current world before jumping to the next world.
Verifying events fire: GA4 has a DebugView (Admin → DebugView) that shows events in near-real-time. To see your own dev/localhost traffic there, install the GA Debugger Chrome extension and enable it before browsing the site. Otherwise localhost traffic is invisible (which is usually what you want — it keeps your own sessions out of production reports).

  • No impact on app performance or behavior
